# office 预览

支持 `word`、`excel`、`ppt` 等格式的文档预览, 使用 [onlyoffice](https://www.onlyoffice.com/) 来实现预览，默认使用公共的服务，后台可自行更改为自己的预览服务，提供自建 [onlyoffice](/advanced/only-office) 的教程.

<img src="/img/2022/08/29/fpMK7V.png"/>

## kkFileView 预览

在「后台 → 显示设置 → kkFileView」中配置服务 URL 和预览打开方式。服务 URL 可以带末尾 `/`，也可以包含部署子路径，例如 `https://preview.example.com/kkview/`。

选择弹窗预览时，可通过 **显示「新标签」按钮** 控制标题栏中的「新标签」按钮，默认开启。开启后，用户可以在新标签页打开当前预览文件。
