# office 预览

支持 `word`、`excel`、`ppt` 等格式的文档预览, 使用 [onlyoffice](https://www.onlyoffice.com/) 来实现预览，默认使用公共的服务，后台可自行更改为自己的预览服务，提供自建 [onlyoffice](/advanced/only-office) 的教程.

## kkFileView 预览

在「后台 → 显示设置 → kkFileView」中配置服务 URL 和预览打开方式。服务 URL 可以带末尾 `/`，也可以包含部署子路径，例如 `https://preview.example.com/kkview/`。

选择弹窗预览时，可通过 **显示「新标签」按钮** 控制标题栏中的「新标签」按钮，默认开启。开启后，用户可以在新标签页打开当前预览文件。


在「实例访问密钥」中填写与 kkFileView 实例一致的密钥；未启用密钥的实例可留空。该密钥会传给浏览器，并通过预览地址中的 `key` 参数发送，访问者可以看到它。系统诊断的反向访问探测也会使用此密钥。

启用「动态水印」后，可在模板中使用 `{siteName}`（站点名）、`{username}`（登录账号，未登录时为“访客”）、`{time}`（浏览器本地预览时间）。模板不能为空白。动态水印通过预览地址参数传入，可被访问者修改，不能作为强制防泄漏措施；效果取决于 kkFileView 版本与文件类型。

预览弹窗标题栏的「刷新缓存」会让 kkFileView 重新获取和转换当前文件。该操作可能耗时较长，仅在手动点击时强制刷新；关闭弹窗后再次打开恢复正常缓存使用。
