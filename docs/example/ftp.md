# FTP / FTPS

FTP 存储源支持普通 FTP、显式 FTPS 和隐式 FTPS。FTPS 使用 TLS 加密，SFTP 则是基于 SSH 的独立协议，使用 SFTP 服务时请选择 SFTP 存储源。

## 配置存储源

1. 在管理后台新增或编辑 **FTP** 存储源。
2. 在 **连接信息 → 服务器地址** 中选择 **连接协议**：

   | 连接协议 | 连接方式 | 常用端口 |
   | --- | --- | --- |
   | FTP（不加密） | 普通 FTP 连接 | 21 |
   | FTPS（显式 TLS） | 建立连接后通过 `AUTH TLS` 启用加密 | 21 |
   | FTPS（隐式 TLS） | 建立连接时立即进行 TLS 握手 | 990 |

3. 填写域名或 IP、服务端实际端口、用户名、密码和基路径。切换协议不会自动修改端口。
4. 根据服务端和网络环境选择主动或被动模式，测试连接后保存。

现有 FTP 存储源默认使用普通 FTP。连接协议按存储源分别保存，可在管理后台随时修改。

## TLS 证书与文件传输

FTPS 校验服务端证书的信任链及连接地址。证书必须在有效期内，并且其域名或 IP 与填写的连接地址匹配；私有 CA 或自签名证书需加入 ZFile 运行环境使用的 Java 信任库。

控制连接与文件传输的数据连接均使用 TLS 加密，数据连接使用 `PBSZ 0` 和 `PROT P`。服务端必须允许加密数据连接；TLS 握手、证书校验或数据连接保护失败时，会报告连接失败。

被动模式仍需在服务端防火墙放行被动数据端口，主动模式仍需允许服务端连接 ZFile 的数据端口。
